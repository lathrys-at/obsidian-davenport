# A-11 — processFrontMatter byte determinism

This protocol produces the recorded fact for Appendix A item 11 of the
design spec. The test plan states the item and its branch in Part 6.1.

## Question

Does `processFrontMatter` write identical bytes for identical inputs in
every environment? An environment is one Obsidian version on one
platform. Every device applies every inbound change to the same linked
note, so the sync design depends on the answer (spec §5.4).

## Procedure

1. Build the probe kit one time: `npm ci`, then `npm run probe:build`.
   The kit and its usage live in
   [`tools/a11-probe/`](../../../tools/a11-probe/README.md).
2. In each environment, install the probe plugin into a scratch vault.
   Then run the command **Run frontmatter probe**. The probe writes the
   file `frontmatter-probe/emission-samples-<timestamp>.json` into the
   vault.
3. Collect one results file from each environment. Compare the files:
   `node tools/a11-probe/compare.mjs <file> <file> ...`.

## Matrix

The minimum matrix is the current Obsidian version and the previous
Obsidian version on macOS. Add platforms and versions when they are
available. Re-verify at each Obsidian minor release, as
[`facts.md`](../facts.md) directs.

## How to read the comparison

- The corpus holds 14 fixtures. The comparison reports one line per
  fixture.
- The word `agree` on a fixture line means that every environment
  emitted the same bytes for that fixture. The comparison proves the
  agreement with one hash per environment.
- The fixture `unparseable` is a control. In a correct run, every
  environment refuses this fixture with the same parse error.
- Determinism holds when the 13 parseable fixtures agree across every
  environment, and every environment refuses the control.

## Branch

- Determinism holds: record the fact. The result validates the [E]/[M]
  fakes of the test harness.
- Determinism fails: the designated-writer redesign is necessary before
  stage 2. The design change goes to the design spec, and not to the
  fact record.
