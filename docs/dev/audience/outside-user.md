# Outside user or contributor

- **Who they are:** someone who found the repo and wants to use it, or to
  contribute.
- **What they already know:** their own problem, and common tooling.
- **What they don't know:** internals, project vocabulary, the issue history.
- **Why they're reading:** to decide whether this solves their problem, and to
  get it running.
- **What they must leave with:** what it does, what it deliberately does not
  do, how to install and run it, and where to go deeper.
- **What wastes their time:** internal jargon, architecture before purpose,
  process detail they will never touch.
